# Attribution

Design Before Code is an original project informed by ideas from several open-source specification, agent-skill, and software-design projects.

## Inspirations

- **Superpowers** — design-before-implementation discipline, explicit review gates, and separating exploration/design from execution.
- **GitHub Spec Kit** — explicit specification artifacts, data-model planning, validation scenarios, and staged implementation readiness.
- **BMAD Method** — user-journey and UX-flow thinking, explicit state coverage, and readiness checks before implementation.
- **DDD Agent Skill** — domain discovery, ubiquitous language, bounded-context thinking, and choosing modeling depth according to problem complexity.
- **softaworks agent-toolkit / database-schema-designer** — relational modeling discipline, normalization, constraints, indexing, and schema-review practices.

This repository intentionally rewrites and combines these ideas around a narrower goal: making product, UX, and data-model decisions understandable and reviewable by humans before AI-generated implementation begins.
